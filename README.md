# PhotoResize Pro ⚡ Precision Image Reducer & Resizer

A modern, high-performance web application to reduce image size in KB, create passport photos, and resize pictures with 100% in-browser privacy. Inspired by Pi7 Image Tool.

Live deployment ready for Vercel, Netlify, and GitHub Pages.

## 🚀 Features (मुख्य विशेषताएं)

1. **Reduce Image Size in KB (KB में साइज कम करें)**:
   - Target Size: 20 KB, 50 KB, 100 KB, 200 KB, 500 KB, 1 MB or custom size.
   - Government Exam Presets (SSC CGL/CHSL, UPSC, IBPS Bank PO, NEET, JEE, PAN Card).
   - High visual quality with smart binary search algorithm.
   - Guaranteed strict under target KB limit.

2. **Multi-Image Batch Support (एक साथ कई फोटो कंप्रेस करें)**:
   - Drag & Drop, File browser, and `Ctrl+V` Clipboard paste support.
   - Single click individual download or **Download All (ZIP)**.

3. **Interactive Quality Comparison (Before & After Slider)**:
   - Original vs Compressed photo side-by-side split slider preview.

4. **Increase Image Size in KB (साइज बढ़ाएं)**:
   - Safe metadata padding to meet portals' minimum file size requirements without altering pixels.

5. **Passport Size Photo Maker & Pixel Resizer**:
   - 3.5 × 4.5 cm (India / SSC / UPSC), 2 × 2 inch (US Visa), Signature (140 × 60 px).

6. **100% Private & Offline (सुरक्षित व बिना इंटरनेट के भी चालू)**:
   - Client-side processing using HTML5 Canvas. No photos are ever uploaded to any server.
